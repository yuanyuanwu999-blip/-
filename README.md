# 视频批量制作助手（精简源码）

这是现有“视频批量制作助手”的精简源码备份，用于迁移到另一台 Windows 电脑。

## 已包含

- 单个视频与批量制作界面
- A/B 段素材处理
- AI 配音开关、随机声音、字幕与封面逻辑
- 背景音乐选择及随机逻辑
- Remotion 渲染代码和配置

## 为缩小体积而排除

- Node.js、Python、FFmpeg 运行环境
- `node_modules`、缓存、测试视频和生成视频
- 旧备份及大体积音乐文件

## 在另一台电脑使用

1. 安装 Node.js、Python 和 FFmpeg。
2. 在 `制作模板` 文件夹执行 `npm install`。
3. 把原电脑 `制作模板/public/music` 中的音乐复制到新电脑相同目录。
4. 双击 `启动视频助手.cmd`。

完整免配置运行包仍保存在原电脑；本仓库主要用于源码备份和继续维护。
