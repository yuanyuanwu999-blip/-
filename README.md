# 视频批量制作助手（精简源码）

这是现有“视频批量制作助手”的可迁移版本，用于安装到另一台 Windows 电脑。

## 已包含

- 单个视频与批量制作界面
- A/B 段素材处理
- AI 配音开关、随机声音、字幕与封面逻辑
- 背景音乐选择及随机逻辑
- 剪辑助手当前使用的全部 13 首背景音乐（普通 MP3，下载 ZIP 也可直接取得）
- 封面字体和 AI 声音试听文件
- 新电脑一键依赖安装程序
- Remotion 渲染代码和配置

## 为缩小体积而排除

- 安装后可自动生成的 Node.js、Python、FFmpeg 运行环境
- `node_modules`、缓存、测试视频和生成视频
- 旧备份及重复的音乐授权原始文件

## 在另一台电脑使用

1. 在 GitHub 页面点击“Code → Download ZIP”并完整解压。
2. 双击 `安装到新电脑.ps1`；如果 Windows 询问，以 PowerShell 运行。
3. 等待 Node.js、Python、FFmpeg、AI 配音、视频渲染及音频模型安装完成。
4. 双击 `启动视频助手.cmd`。

如果直接双击启动文件但电脑尚未安装组件，启动文件会自动打开安装程序。

安装需要联网，完整安装时间取决于网速。安装完成后，核心剪辑、AI配音、字幕、封面、随机音乐以及原视频人声处理功能均在本机运行。
